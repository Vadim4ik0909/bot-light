# ⚡️ Telegram-бот моніторингу відключень світла (Тернопільобленерго)

Бот автоматично збирає дані з офіційного сайту [poweron.toe.com.ua](https://poweron.toe.com.ua/) для обраної адреси:
**м. Бережани (Бережанська ОТГ), вул. Героїв Майдану, буд. 2-А (Підчерга ГПВ: 2.1)**.

---

## 🌟 Основні можливості

- 🔴 **Сповіщення про відключення:** як тільки настає час планового вимкнення за графіком.
- 🟢 **Сповіщення про включення:** щойно електропостачання відновлюється згідно з розкладом.
- ⏱ **Попередження за 15 хвилин:** завчасне нагадування підготуватися до відключення (зарядити пристрої, вимкнути чутливу техніку).
- 🔄 **Моніторинг змін графіка:** автоматичне сповіщення користувачів, якщо обленерго оновило розклад на поточний або наступний день.
- 📊 **Зручні команди та меню:**
  - `💡 Поточний стан` — статус просто зараз (чи є світло, скільки часу залишилося до наступної зміни).
  - `📅 Графік на сьогодні` — повний розклад на добу з кольоровою шкалою та годинами.
  - `📆 Графік на завтра` — графік на наступний день (як тільки з'являється на сайті обленерго).
  - `🚨 Аварійні роботи` — перевірка позапланових аварій чи ремонтних робіт.
  - `⚙️ Налаштування` — можливість індивідуально вмикати/вимикати сповіщення та змінювати час попередження (15 хв / 30 хв / вимк).

## 🚀 Швидкий запуск

### Крок 1. Отримання токена бота
1. Відкрийте Telegram і знайдіть бота [@BotFather](https://t.me/BotFather).
2. Надішліть команду `/newbot` та слідуйте інструкціям (введіть назву та username бота).
3. Скопіюйте отриманий `API TOKEN` (наприклад, `7123456789:AAH...`).

---

### Крок 2. Налаштування файлу `.env`
У папці проекту вже створено файл `.env`. Відкрийте його та вставте ваш токен:
```ini
BOT_TOKEN=7123456789:AAH...ваш_токен_від_BotFather
```

Інші параметри вже налаштовані під вашу адресу:
```ini
OTG_ID=17
OTG_NAME=Бережанська ОТГ

CITY_ID=136
CITY_NAME=Бережани

STREET_ID=1663
STREET_NAME=вул. Героїв Майдану

BUILDING_NAME=2-А
CHER_GPV=2.1

CHECK_INTERVAL_SECONDS=60
TIMEZONE=Europe/Kyiv
```

---

### Крок 3. Запуск бота

#### Варіант А: Локальний запуск (Python)
Віртуальне оточення вже створене в папці `.venv`. Для запуску виконайте:

```bash
# Активація віртуального оточення
source .venv/bin/activate

# Запуск бота
python main.py
```

Або однією командою без активації:
```bash
.venv/bin/python main.py
```

---

#### Варіант Б: Запуск у Docker (рекомендовано для серверів)
У проекті налаштовані `Dockerfile` та `docker-compose.yml`:

```bash
docker compose up -d --build
```

Перегляд логів:
```bash
docker compose logs -f
```

Зупинка:
```bash
docker compose down
```

## 🛠 Структура проекту

```
bot-light/
├── config.py              # Конфігурація та налаштування адреси
├── api_client.py          # Асинхронний клієнт для API poweron.toe.com.ua
├── schedule_parser.py     # Парсинг 48 часових слотів, розрахунок інтервалів та статусів
├── database.py            # Збереження підписників та налаштувань (aiosqlite)
├── notifier.py            # Фоновий сервіс щохвилинної перевірки та розсилки сповіщень
├── keyboards.py           # Меню та інтерактивні inline-кнопки Telegram
├── handlers.py            # Обробка команд (/start, /status, /today, /tomorrow, /settings)
├── main.py                # Головний файл запуску бота
├── requirements.txt       # Список залежностей Python
├── Dockerfile             # Контейнеризація бота
├── docker-compose.yml     # Скрипт запуску в Docker
└── .env                   # Файл секретів і налаштувань (токен)
```
